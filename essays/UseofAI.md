## AI in Education of Software Engineering
AI has been the biggest boom in the tech industry within the last year or so. With the ability to solve complex problems in math and science, code, and write essays(not great one), AI's like ChatGPT have been the latest buzz in education. Because of its streamlined nature and ease of use, AI sparks questions about what the line between helpful tool and cheating machine. For this, it falls to the user. The nature of AI is prompt based, if you write "Write this code for me" will you actually be learning it? The more specific your prompt i, my favorite this semester has been "Without showing any code, explain the thought process behind doing xxx and helpful syntax that would speed up the coding process." This has helped me learn about the code I am writing rather than copy pasting straight from ChatGPT. The only exception was WODs, this is because in a credit/no-credit system, you'd do anything for the credit especially under a time constraint.
## 1. Experience WODs e.g. E18
Because the Experiences had tutorial videos, I didn't see myself using AI as much on these. Sometimes i would ask it for specific question, treating it more like a personalized Stackoverflow or Geeksforgeeks. I was more likely to ask for help from a friend rather than AI.
## 2. In-class Practice WODs
For the more simple practice WODs, I would use the prompt I stated in the introduction to coach me through the syntax of different frameworks. When the WODs started having too many files, it became hard to rely on ChatGPT to explain becuase it would have to pick components from different files. This was especially relevent when we worked with next.js and prisma. ChatGPT sucks at command line prompts.
## 3. In-class WODs
I used AI for a little over half the WODs. Some were simple and straight forward where they are doable just with the basic practice given in class and from assignments. I noticed that some WODs were difficult and had trouble implementing different frameworks, especially bootstrap and some react components. I would have liked to use AI less but if my grade is on the line, I'm going to use whats available to pass.
## 4. Essays
AI was only used in essays to find synomyms, fix a wordy sentence, or fix gramatical mistakes. This was mostly done with Grammarly, ChatGPT and later ClaudeAI as I think it responds less robotic than ChatGPT. All concepts an basic structure are human made.
## 5. Final project
On the final project I used Copilot. The intergration into vsCode made it a little easier to fix syntax and typing issues in the template page. My team leader for the final project was very advanced and helped my group figure out many technical and coding issues with comments and during our meetings. Copilot had issues recognizing ESLint errors and often had coding suggestion that either broke the code or provided more ESLint errors. It was somewhat successful when given prompts like "Translate this code xxx so it fits with the syntax and variables in component xxx". This was used a lot since our final project had a lot of recycled elements and it saved the tedious work of finding the one to one variable matches for different components and style.css files.
## 6. Learning a concept / tutorial
The most helpful way to use AI. Helped me learn the framework taught in class and broke down the basic concepts of html and css for me during the beginning of the class. I also used it a lot for this after when we switched from bootstrap to react because of how fast the class moved when skipping between frameworks.
## 7. Answering a question in class or in Discord
If you use AI in class or for a question asked on Discord, maybe you shouldn't be answering. What if they have a followup question, are you going right back to ChatGPT? Its best to answer question if you are confident in your solution and can explain it authentically.
## 8. Asking or answering a smart-question
I didn't have many smart-question while taking this course. Most of my questions came from downloading external products incorrectly like prisma and pgAdmin which took me a week and three different people to install and work properly. AI doesn't understand software installations and how to mesh installation instructions to your devices current setup.
## 9. Coding example e.g. “give an example of using Underscore .pluck”
I used coding examples a lot when learning functional programming. I would get the built in . functions mixed up and it helped me make sample problems and then I would write out the code for the problem to be graded by ChatGPT.
## 10. Explaining code
Helped me understand that jumps from framework to framework as a lot of it had similar function but different syntax. This allowed me to better understand bootstrap in terms of regular html and css and then react in terms of bootstrap.
## 11. Writing code
This was only done on timed WODs because I needed the grade and during the final project for areas like prisma and db manipulation. I would usually ask it for the soltuion and then work backwords.
## 12. Documenting code
AI usually automatically puts comments so that is handy when looking through large files. I never used it directly to add comments becuase I think a decent amount of coding that we did was copy pasted from other assignments just changing the wording. The fact that not a lot of people were looking at my code also meant to me that I could be a little bit more lenient of the commenting that I do.
## 13. Quality assurance e.g. “What’s wrong with this code <code here>” or “Fix the ESLint errors in <code here>”
I would use Copilot and ChatGPT to explain why certain lines of code had red squiggly lines under them and it would usualy provide a bad solution becuase it only has the context of either the line or file that it is in. This proved super difficult in the final project as so many features used codes and functions from other finals that it's hard to track where everything in one file is original from.
## 14. Other uses in ICS 314 not listed
I basically used it as a coder in dire situations, a replacement from forum based website for explanations, and a spell checker/grammar/thesaurus helper. I did not want to rely on AI as heavily as I did but I fell behind in the middl eof the semester and had trouble catching up.
